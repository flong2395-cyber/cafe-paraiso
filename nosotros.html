Nuestra empresa

Una identidad demostrativa preparada para adaptarse.

Café Paraíso es la identidad utilizada por este proyecto de portfolio para mostrar una experiencia digital completa alrededor del café.

Un caso de uso adaptable

Una base digital para presentar productos y servicios.

Café Paraíso no representa en este repositorio una empresa real ni una trayectoria histórica concreta. Es un nombre demostrativo aplicado a una plataforma que reúne catálogo, comercio y gestión empresarial.

El contenido puede configurarse para una instalación propia sin atribuir a la nueva identidad datos, logros o antecedentes no documentados.
